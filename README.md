# 🎮 Edutaiment

Aplikasi **Edutainment** (*Education & Entertainment*) interaktif yang menggabungkan konsep pembelajaran dan hiburan digital untuk menciptakan pengalaman belajar yang lebih menarik, intuitif, dan menyenangkan.

---

## ✨ Fitur Utama

- **Pembelajaran Interaktif:** Menyajikan materi edukasi dengan pendekatan visual dan interaktif agar mudah dipahami pengguna.
- **Gamifikasi / Kuis Edukatif:** Dilengkapi elemen permainan atau tantangan untuk menguji pemahaman sekaligus meningkatkan motivasi belajar.
- **Antarmuka Ramah Pengguna:** Desain antarmuka yang bersih dan responsif untuk kenyamanan eksplorasi konten.
- **Sistem Skor & Progres:** Memantau perkembangan dan pencapaian pengguna selama menggunakan aplikasi *(sesuaikan jika ada)*.
